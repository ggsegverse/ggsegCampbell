# ggsegCampbell: Campbell Cortical Atlas (1905) for the 'ggseg' Ecosystem

Campbell (1905) cortical atlas for the 'ggseg' ecosystem. Provides a
unified 'ggseg_atlas' object with both 2D polygon geometry and 3D vertex
indices, for use with 'ggseg' and 'ggseg3d'.
